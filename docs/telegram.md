# Telegram 账号：四种号型与真实差别

同一个"Telegram 账号"，价格能从 3 块到 50 块，差的不是运气，是号型。

## 新号（未满 7 天）

最便宜的一档，也最脆弱。

Telegram 对新注册账号有明确的风控期：

- 主动私聊陌生人，大概率被限制发消息
- 短时间加大量群，会被判定为营销号
- 部分 VOIP 号段注册的账号，直接无法给陌生人发消息

**能做什么**：收验证码、临时登录、看内容。

**不能做什么**：拉人、群发、给陌生人发第一条消息。

---

## 老号（半年 / 一年 / 五年）

价格阶梯很明显，但你买的其实是"**已经通过早期风控**"这件事。

老号的价值不在年龄数字，而在于它有过正常使用记录：加过群、发过消息、没被举报过。Telegram 的风控模型对这类账号的容忍度高得多——同样的操作，新号被限制，老号可能没事。

**但老号也可能带着问题**：

- 前任使用者可能用它发过广告，账号已经被降权
- 可能挂着别人还在用的活跃会话
- 可能绑定着别人的手机号

所以买到手第一件事不是用，是检查（见最后一节）。

## API 接码号

用接码平台的号码注册，注册完成后号码会被平台回收，再卖给下一个人。

**核心风险：你登录着的时候没事，一旦掉线，可能再也收不到验证码。**

因为那个号码已经属于别人了。

所以这类号到手必须立刻做两件事：

1. 设置里绑定自己的邮箱
2. 开启两步验证（2FA）

做完这两步，即使原号码被回收，你仍可以通过邮箱 + 2FA 登录。

**没做这两步就掉线，号基本等于废了。**

## 会员号（Premium）

带 Telegram Premium 订阅的号。

价格里包含会员成本，通常比普通号贵一截。要注意三件事：

- **会员还剩多久**：卖家说"带会员"，可能是还剩 3 天
- **哪个区**：不同区定价不同，续费方式也不同
- **能不能续**：如果卖家用的是共享支付方式，会员到期后你未必能自己续

会员是订阅制，卖家用的支付方式一旦被 Telegram 判定异常，订阅会被取消。这不是账号质量问题，是支付链路问题。

## 怎么检查一个号的状态

登录后按这个顺序看：

### 1. 活跃会话

```
设置 → 隐私和安全 → 活跃会话
```

正常情况只有你这一台设备。如果看到陌生设备、陌生地区，说明卖家或前使用者还挂着。

**处理**：直接点"终止所有其他会话"。

### 2. 是否能正常发消息

给 `@Telegram`（官方账号）发一条消息。它是机器人，不会回复，但如果你的号被限制，会直接报错。

### 3. 是否能加群

随便找一个公开群，点加入。如果提示"无法加入"或"你被限制"，说明账号处于受限状态。

### 4. 是否绑定了邮箱

```
设置 → 隐私和安全 → 登录邮箱
```

没有邮箱 = 掉线就找不回来。

### 5. 两步验证状态

```
设置 → 隐私和安全 → 两步验证
```

没开的话立刻开，密码记在自己手里。

## 一句总结

```
只收验证码          新号够用
长期用、绑重要服务    一年以上 + 带邮箱
加群、发消息         半年以上，且验过活跃会话
只想看内容           共享号也行
```

买之前先想清楚用途，比纠结价格有用得多。
