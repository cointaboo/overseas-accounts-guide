# Apple ID：区服比价格重要

Apple ID 的价格差主要来自区服，不是账号质量。买之前先确定你要哪个区，再看价格。

## 区服怎么选

| 区服 | 适合什么 | 代价 |
|---|---|---|
| 美区 | App 最全，礼品卡最容易买 | 部分 App 需要美国支付方式 |
| 日区 | 游戏、漫画、部分独占应用 | 日元结算，需要日区支付或礼品卡 |
| 土区 | 订阅类价格最低 | 支付方式难搞，账号被封率高 |
| 港区 | 中文界面，支持银联 | 价格中等，App 数量略少于美区 |
| 菲区 / 尼区 | 低价区内购 | 支付渠道不稳定 |

**选区的判断标准不是"哪里便宜"，是"你能不能付款"。**

一个土区账号，如果没有任何土耳其支付方式或礼品卡，你连一个免费 App 之外的付费项目都买不了。便宜没有意义。

## 独享与共享

**独享**：只有你一个人用，可以改密码、绑自己的手机号、开双重认证。

**共享**：多人共用一个账号，通常只用于下载已购应用。不能改密码，随时可能被踢下线，也可能被别人绑走。

用途决定选择：

```
只想下个 App / 用几天    共享号够用
要长期用、要买内购      必须独享
要绑支付方式            必须独享，且自己改密码
```

共享号最大的风险不是被踢，是**你不知道还有谁在用**。如果有人在上面买了东西、或者触发了风控，号会一起完蛋。

## 为什么不建议登 iCloud

这是买来的号最容易犯的错。

登录 iCloud 意味着：

- 设备与账号绑定
- 账号被封时，设备可能被锁定（激活锁）
- 账号里的照片、通讯录、备份与你的设备数据混在一起

**正确做法**：

```
设置 → 你的名字（iCloud）       ← 用你自己的账号
设置 → App Store               ← 用买来的账号
```

只在 App Store 里登录，即使这个号明天被封，你的手机、照片、备份都不受影响。

## 被停用怎么处理

Apple ID 被停用分三种，处理方式完全不同。

### 1. 密码错误太多次

提示"Apple ID 已因安全原因被停用"。

**处理**：等 1 小时，或用受信任设备解锁，或走 iforgot.apple.com 重置。

这类通常能恢复。

### 2. 双重认证卡住

要求输入验证码，但绑定的是别人的手机号或旧设备。

**处理**：走账号恢复流程（iforgot.apple.com → 无法使用受信任设备），审核期通常几天到两周。

成功率取决于你能否提供注册信息。

### 3. 真被封

通常是异地登录 + 支付异常 + 多设备同时使用触发。

**处理**：只能申诉。需要提供注册时的生日、安全问题、原始支付方式、购买凭证。

买来的号基本拿不出这些，所以**第三种情况成功率很低**。

## 验活清单

到手后按顺序做，十分钟内能判断号有没有问题：

```
□ 能登录 App Store（不登 iCloud）
□ 已购项目里能看到内容（说明不是空号）
□ 能下载一个免费 App
□ 地区与描述一致
□ 双重认证能正常收到验证码（如果是独享号）
□ 改密码成功
```

任何一项失败，趁质保期赶紧换。
