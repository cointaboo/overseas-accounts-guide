# 到手 10 分钟验活清单

不管从哪买，到手先做这几步，能过滤掉绝大多数问题号。

**原则：先验，再改，最后才放心用。**

## Telegram

```
□ 能正常登录，不需要额外验证码
□ 设置 → 活跃会话：只有你这一台设备
□ 能给 @Telegram 发消息（不报错即正常）
□ 能加入一个公开群（不被限制）
□ 改密码
□ 绑定邮箱
□ 开启两步验证
```

**顺序很重要**：先看活跃会话（判断有没有人跟你共用），再改密码。

如果发现陌生设备，先"终止所有其他会话"，再改密码。顺序反了的话，对方可能在你改完密码之前就把你踢下线。

## Apple ID

```
□ 能登录 App Store（只登 App Store，不登 iCloud）
□ 已购项目里能看到内容
□ 能下载一个免费 App
□ 地区与描述一致
□ 独享号：能收到双重认证验证码
□ 能改密码
```

**注意**：登 App Store 的路径是 `设置 → App Store → 登录`，不是 `设置 → 你的名字`。后者是 iCloud，登错会带来激活锁风险。

## 邮箱账号

```
□ 能登录网页版
□ 能收到一封测试邮件
□ 能发出邮件（部分号只能收不能发）
□ 检查转发规则（有没有人偷偷转发）
□ 检查恢复邮箱和手机号（是不是别人的）
□ 改密码
□ 换掉恢复信息
```

最后两条最容易被忽略。很多问题号不是不能用，而是**卖家保留了恢复方式**，随时能拿回去。

只改密码不够，必须把恢复邮箱、恢复手机、备用验证方式全部换成自己的。

## 通用：检查后门

这几项不分品类，都要看：

### 1. 登录设备/会话列表

所有平台都有"已登录设备"页面。清空陌生设备是第一步。

### 2. 转发与自动回复规则

邮箱类尤其重要。有人会设置"收到特定关键词的邮件自动转发到我的地址"，这样你的验证码会同时发给别人。

### 3. 绑定的第三方应用

Telegram、Google 都有"已授权应用"列表。陌生应用意味着有人用这个号做过别的事。

### 4. 支付方式

如果账号里挂着别人的卡或订阅，一旦对方取消或触发风控，你的号会被连带影响。

## 出问题怎么处理

**质保期内**：直接找卖家换。保留截图（报错信息、时间、账号 ID），大部分纠纷靠截图就能解决。

**质保期外**：分情况。

```
密码被改         → 走平台找回，需要邮箱/手机还在你手上
账号被封         → 申诉，成功率取决于能否提供注册信息
无法登录         → 先确认是网络问题还是账号问题（换个网络试）
```

**最没用的事**：反复重试登录。风控会把"短时间多次失败"当成攻击行为，导致临时锁定，反而更难恢复。

---

## 一张图记住顺序

```
登录 → 查会话 → 清陌生设备 → 改密码 → 绑邮箱 → 开 2FA → 换恢复信息
```

任何一步失败，趁质保期处理，别拖。
