## 五种失败原因

按出现频率排序：

### 1. 号段在黑名单里

接码平台用的绝大多数是 VOIP 号段。OpenAI、Google、Telegram、TikTok 都有专门的 VOIP 黑名单，注册时直接拒绝。

这不是"短信没收到"，是**根本没发**。

### 2. 号码已被用过

同一个号码被注册过该服务，系统会直接拒绝，甚至不提示原因。

接码平台的号码是循环使用的，热门平台的号码基本都被用过。

### 3. 平台没真正发出短信

部分低价平台只是"显示已发送"，实际上游渠道已经断了。

判断方法：换一个号再试，如果所有号都秒失败，是平台问题；如果个别号成功，是号段问题。

### 4. 短信延迟

超过 5 分钟基本可以放弃。等下去只会把号码占住，钱也退不回来。

### 5. IP 与号码国家不匹配

用中国 IP 配美国号，风控会直接拦。注册时 IP 要和号码国家一致。

## 怎么提高成功率

按这个顺序做：

```
1. 优先选美国实体号段（不是 VOIP）
2. 注册时挂对应国家的网络出口
3. 失败立刻换号，别反复重试同一个号码
4. 一次成功就马上绑定邮箱 / 开两步验证
```

**为什么强调"立刻绑定"**：接码号码会被回收。你只有很短的时间窗口把它变成"属于你的账号"。错过了，下次掉线就找不回来。

## 哪些服务用接码过不去

实际测试中，这些服务的风控最严：

| 服务 | 难度 | 说明 |
|---|---|---|
| Google / Gmail | 极高 | VOIP 号段基本全拒，还会要备用验证方式 |
| OpenAI / ChatGPT | 高 | 部分号段可用，但失败率高 |
| WhatsApp | 高 | 会检测号码历史，被用过的直接拒 |
| Telegram | 中 | 相对宽松，但新号仍受风控 |
| Discord | 中 | 部分号段可用 |
| TikTok | 中高 | 依赖地区和号段 |

难度越高，越值得花几块钱买"实体号"而不是"VOIP 号"。

## 成本与选择

```
最低档  VOIP 号，几分钱    成功率低，适合试
中档    实体号，几毛到几块  成功率高，适合重要服务
高档    专属号，几块到几十  号码独享，可长期用
```

如果只是注册一个临时账号，最低档够用。

如果是**要长期用的账号**，直接买专属号。因为账号的价值远高于那几块钱的差价，而接码号掉线后基本就废了。

## 一个常被忽略的细节

接码平台显示"成功"不等于"注册成功"。

有些服务会在收到验证码之后再做一次风控判断，比如要求补充邮箱、要求二次验证、或者直接封号。

所以完整的验证流程是：

```
收到验证码 → 填进去 → 能正常登录 → 能正常使用 → 才算成功
```

只看到验证码通过就以为结束了，是最常见的误判。
