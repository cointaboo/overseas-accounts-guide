## 三个最常见的误判

### 1. 以为便宜就是赚了

账号价格差 10 倍，通常不是同一个东西。3 块的是共享号或随时被找回的号，30 块的是独享带邮箱的老号。

**先确定用途，再比价。**

### 2. 以为能登录就是好号

能登录只是最低门槛。真正的判断标准是：

```
有没有陌生设备还挂着
有没有绑定别人的恢复邮箱
能不能正常发消息 / 加群
掉线后能不能自己找回来
```

### 3. 以为改密码就安全了

改密码不够。卖家如果保留了恢复邮箱或手机号，随时能把账号拿回去。

**必须同时换掉：密码 + 恢复邮箱 + 恢复手机 + 备用验证方式。**

## 快速判断表

| 用途 | 需要的配置 | 不必多花钱买 |
|---|---|---|
| 只收验证码 | 新号 | 老号、会员号 |
| 长期使用 | 一年以上 + 绑定邮箱 | 会员号 |
| 加群 / 发消息 | 半年以上 + 验过活跃会话 | 五年号 |
| 下载 App | 共享 Apple ID 够用 | 独享号 |
| 买内购 / 绑支付 | 必须独享 + 改密码 | 无 |

## 通用验活顺序

```
登录 → 查活跃会话 → 清陌生设备 → 改密码 → 绑邮箱 → 开两步验证 → 换恢复信息
```

任何一步失败，趁质保期处理。详细清单见 [验活清单](docs/verify.md)。
