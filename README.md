## 1. 先搞清楚你要买的是什么

账号交易里最容易亏钱的地方，不是价格，是**买错类型**。

同一个"Telegram 账号"，可能是：

- 全新注册、从未登录过的号
- 注册满一年、有历史聊天的老号
- 用 API 接码注册、手机号已释放的号
- 带会员（Premium）的号

价格可能差 10 倍，能做的事也完全不同。买之前先问自己一句：**我要它干什么？**

| 用途 | 需要的号型 | 不需要的 |
|---|---|---|
| 收验证码、临时注册 | 新号即可 | 老号、会员号 |
| 长期使用、绑定重要服务 | 一年以上老号 + 带邮箱 | 全新号 |
| 加群、发消息 | 半年以上，有过正常使用痕迹 | 刚注册的空号 |
| 只看内容 | 共享号够用 | 独享号 |

## 2. Telegram 账号：四种号型与它们真正的区别

### 新号（未满 7 天）

最便宜，也最脆弱。Telegram 对新注册账号有风控期：

- 主动私聊陌生人容易被限制
- 短时间内加大量群会被判定为营销号
- 部分地区的号段（尤其是 VOIP 号段）直接被拒

**适用**：只需要一个能收验证码的号码，用完就丢。

### 老号（半年 / 一年 / 五年以上）

价格阶梯明显，但买到的是"**已经通过早期风控**"这件事。

老号的核心价值不是年龄本身，而是它已经有过正常使用记录——加过群、发过消息、没被举报过。Telegram 的风控模型对这类账号容忍度高得多。

**注意**：老号也可能带着历史问题。买到后第一件事是检查：

```
设置 → 隐私和安全 → 活跃会话    有没有陌生设备还在登录
设置 → 隐私和安全 → 屏蔽用户    有没有被大量举报的痕迹
```

### API 接码号

用接码平台的号码注册，注册完成后号码通常会被平台回收再卖给别人。

这意味着：**你登录着的时候没事，但一旦掉线，可能再也收不到验证码。**

所以这类号到手后必须立刻做两件事：

1. 在设置里绑定自己的邮箱
2. 开启两步验证（2FA）

绑定之后，即使原号码被回收，你仍然可以通过邮箱 + 2FA 找回。

### 会员号（Premium）

带 Telegram Premium 订阅的号。价格里包含了会员成本，通常比普通号贵一截。

**风险**：会员是订阅制，卖家可能用的是共享支付方式或黑卡。这类订阅随时可能被 Telegram 取消。买之前问清楚：会员还剩多久、是哪个区、能不能续。

## 3. Apple ID：区服比价格重要

Apple ID 的价格差异主要来自区服，不是账号质量。

### 常见区服与用途

| 区服 | 典型用途 | 注意 |
|---|---|---|
| 美区 | App 最全、礼品卡好买 | 部分 App 需要美国支付方式 |
| 日区 | 游戏、漫画、部分独占应用 | 日元结算，价格常低于美区 |
| 土区 | 订阅价格最低 | 需要土耳其支付方式或礼品卡 |
| 港区 | 中文界面、支持银联 | 价格中等 |
| 菲区 / 尼区 | 低价区内购 | 支付方式难搞 |

### 独享 vs 共享

- **独享**：只有你一个人用，可以改密码、绑自己的手机号。
- **共享**：多人共用一个账号，只用于下载已购应用，不能改密码，随时可能被踢下线。

共享号适合"只想下个 App"，不适合"要长期用 iCloud"。

### 锁号怎么办

Apple ID 被停用分三种情况：

1. **密码错误太多次** —— 等 1 小时后重试，或用受信任设备解锁
2. **双重认证卡住** —— 需要当初绑定的手机号或恢复密钥
3. **真被封** —— 通常是异地登录 + 支付异常触发，只能走申诉

第三种情况成功率不高，尤其是买来的号，因为申诉需要提供注册时的信息（生日、安全问题、原始支付方式），而这些你都没有。

**所以：买来的 Apple ID 不要登 iCloud，只登 App Store。** 这样即使号被封，也不会影响你的设备和数据。

## 4. ChatGPT / Claude 订阅：三条路各自的代价

### 路一：自己开虚拟卡充

- 优点：账号完全属于自己
- 缺点：虚拟卡平台大量停服，能用的越来越少；被 OpenAI 判定为高风险支付会直接封号

### 路二：找人代充

- 优点：便宜、快
- 缺点：代充方用的是自己的支付渠道，一旦被判定欺诈，你的账号会被连带封禁；且代充方能看到你的账号状态

### 路三：买已开通的成品号

- 优点：到手即用
- 缺点：账号不是你注册的，找不回；续费麻烦；卖家可能保留恢复方式

**没有一条是完美的。** 选择取决于你更在意"账号归属"还是"省事"。

如果是长期用、有重要对话记录，选路一。如果只是临时用一两个月，路三的成本最低。

## 5. 接码：为什么你总是收不到验证码

接码失败通常不是平台的问题，是**号段被目标服务拉黑**。

常见原因排序（按出现频率）：

1. **号段在黑名单里** —— 接码平台用的都是 VOIP 号段，OpenAI、Google、Telegram 都有专门的 VOIP 黑名单
2. **号码已被用过** —— 同一个号码被注册过该服务，系统直接拒绝
3. **平台没真正发出短信** —— 部分低价平台只是"显示已发送"
4. **短信延迟** —— 超过 5 分钟基本可以放弃
5. **IP 与号码国家不匹配** —— 用中国 IP 配美国号，风控会拦

**提高成功率的顺序**：

```
1. 优先选美国实体号段（不是 VOIP）
2. 注册时挂对应国家的 IP
3. 失败立刻换号，别反复重试同一个号码（会触发频率限制）
4. 一次成功就马上绑定邮箱，别等
```

## 6. 到手 10 分钟验活清单

不管从哪买，到手先做这几步，能过滤掉 90% 的问题号。

### Telegram

```
□ 能正常登录，不需要二次验证码
□ 设置 → 活跃会话：只有你这一台设备
□ 能正常发消息给 @Telegram（官方账号，不会回复但不会报错）
□ 能加入一个公开群（不是被限制状态）
□ 立刻改密码 + 绑定邮箱 + 开两步验证
```

### Apple ID

```
□ 能登录 App Store（只登 App Store，不登 iCloud）
□ 能看到已购项目（说明不是空号）
□ 尝试下载一个免费 App，能正常下载
□ 检查地区是否与描述一致
```

### 邮箱类

```
□ 能登录网页版
□ 能收到一封测试邮件
□ 检查是否有转发规则被设置（卖家可能留了后门）
□ 检查恢复邮箱和手机号是不是别人的
```

**最后一条最容易被忽略**：很多问题号不是不能用，而是卖家保留了恢复方式，随时能拿回去。改密码不够，必须把恢复信息也换掉。

## 7. 常见骗局与识别方法

**1. 价格低得离谱**

市场价 10 块的号卖 2 块，要么是共享号冒充独享，要么是随时会被找回的号。

**2. 只收加密货币、不走平台担保**

不是所有收 U 的都是骗子，但拒绝任何担保方式的，风险显著更高。

**3. "先付款再发号"但没有售后**

正常卖家会明确写质保期。含糊其辞的，出问题基本找不到人。

**4. 发来的号要求"先确认收货再给密码"**

这是典型的一号多卖套路。

**5. 承诺"永久质保"**

账号类商品不存在永久质保，因为封号取决于平台风控，不取决于卖家。看到"永久"两个字，直接降一档信任。
